# Proveedores de prospección V3

El sistema usa lotes de fuentes públicas para descubrir e incorporar empresas. Codex interpreta la intención de búsqueda. La procedencia de las fichas viene del catálogo configurado localmente o del archivo preparado con evidencia. La ficha conserva URL, fecha de consulta, descripción del hecho y nivel de confianza.

## Actualizar las fuentes

1. Ubicá candidatos con una fuente cuyo uso esté permitido y contrastá cada ficha con la web corporativa. Guardá solo datos publicados para la actividad de la empresa. Si varios canales publicados discrepan, dejá el campo pendiente.
2. Prepará un JSON `discoveryFile` versión 1, con hasta 100 fichas y el formato de `fixtures/investigacion-demo.json`. Registrá en cada evidencia su URL, la fecha efectiva de consulta, un proveedor reconocible y el hecho comprobado. Usá una descripción propia. Guardá los lotes reales en la carpeta privada del operador.
3. Incorporá el archivo desde Prospección con IA o con `scripts/research.ps1`. La opción de fuentes cotejadas representa una confirmación editorial de la evidencia. Las fichas dudosas se pueden enviar sin esa confirmación para revisar desde el lote. El historial conserva los resultados y la cartera aplica sus exclusiones y coincidencias.
4. Para evaluar otro proveedor, revisá la licencia de cada conjunto, permiso de almacenamiento y exportación, atribución, cuotas, facturación, uso de datos comerciales y cobertura. Probá primero con una muestra aislada y conservá el origen de cada dato.

La señal de reservas puede ser un canal de consulta o un motor de reserva. Registrá cuál se observó antes de redactar un borrador comercial. Una señal de compra, reserva o autoservicio sirve para proponer una conversación sobre ese flujo.
