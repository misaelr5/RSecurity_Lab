# Operación

1. Importá prospectos CSV o JSON v1. Revisá el resumen y las coincidencias por dominio, correo o teléfono antes de considerar que dos fichas pertenecen a la misma organización.
2. En una ficha registrá fuentes y evidencia. Agregá un activo público con tipo, fecha, confianza, estado y enlace a la fuente. La existencia de un dominio no otorga permiso para auditar.
3. Registrá los hitos que ocurrieron en el pipeline. Consultá en el dashboard los estados y respuestas explícitas. La prioridad mide qué tan preparada está la ficha para contacto bajo los pesos definidos.
4. Prepará un borrador de correo o WhatsApp y revisalo. Si el prospecto tiene exclusión, la app bloquea creación y aprobación.
5. En Auditorías podés comprobar el fixture, cargar un resumen defensivo redactado o verificar una autorización documental.
6. Abrí el informe desde la ficha o la corrida. Revisá su versión, exportá MD/HTML/CSV o elegí Imprimir o guardar PDF para obtenerlo desde el navegador.
7. En Configuración creá una copia antes de cambios importantes. Para verificar una recuperación, restaurá a otro nombre y validá datos antes de elegirlo como base activa.
